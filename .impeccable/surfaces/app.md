# Surface: Main soundboard (/)

Visitor mode: Operate

## Scope

Primary soundboard grid, add/edit flows, categories, settings for overlap behavior, empty state.

## Direction contract

THESIS: The grid of collectible sound stickers is the entire first screen — no hero, no marketing. Category chips sit under a compact reef header; add sound is a fixed dock control.

OWN-WORLD: Milky aqua canvas with subtle paper grain; pads as glossy scrapbook stickers with thick white outlines, slight rotation, and sticker shadows. Accent coral for primary add action. Mochiy Pop One for pad titles, Kosugi Maru for UI chrome. SVG jellyfish and bubbles only in margins/empty state, never over controls.

STORY: Visitor sees pads immediately; tap plays with bounce + ripple; long-press or edit affordance opens bottom sheet for rename/color/icon/replace/delete.

FIRST VIEWPORT: Safe-area header (~56px) with app name and overlap toggle; horizontal category scroller; 2-column pad grid filling remaining height; floating “+ Add sound” pill anchored above bottom safe area. Empty state: centered jellyfish illustration, one line invite, same add button.

FORM: Scrapbook sticker grid on underwater diary paper — asymmetric sticker tilts, not uniform cards.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
