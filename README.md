# Magaggie

Soundboard kawaii submarino (*Sonidos del arrecife*): sube audio, personaliza pads tipo sticker y tócalos para reproducir.

Soundboard web mobile-first: sube audio, personaliza pads tipo sticker y tócalos para reproducir. Los datos quedan en tu navegador (IndexedDB).

## Ejecutar en local

```bash
npm install
npm run dev
```

Abre la URL que muestra Vite (normalmente `http://localhost:5173`).

## Compilar

```bash
npm run build
npm run preview
```

## Funciones

- Subida de MP3, WAV, OGG, WebM (hasta 10 MB)
- Colores, iconos, nombres y colecciones personalizables
- Modo solitario (un sonido a la vez) o reproducción superpuesta
- Editar, reemplazar audio, reordenar y eliminar con confirmación
- Pads accesibles por teclado y soporte de movimiento reducido

## Diseño

El proyecto usa skills de [Impeccable](https://impeccable.style) en `.cursor/skills/impeccable`.
